# 更好的唱片（可连电脑） · 饥荒联机版 mod

> 版本 **1.1.0**

给游戏里的**留声机**加一张「连接电脑」唱片：

* 唱片放进留声机、留声机转起来 → 电脑开始放歌
* 离留声机越近声音越大，走远就听不清（20 格以外静音）
* 声音还会跟着留声机在你屏幕上的左右位置走左右声道
* 把唱片拿走 / 拆掉留声机 → 电脑立刻安静，歌不停，进度继续走
* **把留声机拿在手上、放进背包，音乐继续放**（可在 Mods 菜单里开关）
* 游戏关掉 → 播放器变回普通播放器，正常出声

---

## 一次说清一个物理限制

饥荒的音频引擎是 FMOD，**只能放打包好的音效文件，不接受外部实时音频流**。
所以「把电脑声音塞进游戏引擎、再由引擎喇叭放出来」做不到 —— 任何 mod 都做不到。

这套东西做的是：让**你电脑上的声音**完全听留声机的指挥（有没有声、多大声、偏左偏右）。
声音本来就从同一对音箱出来，听感上就是「从留声机里放出来」的效果。

### 换图标（mod 和播放器都用这张）

把新图（正方形，建议 512×512 以上）放到工程目录，然后依次运行：

```powershell
$py = "D:\venv_oscilloscope\Scripts\python.exe"
& $py tools\img_to_tex.py 新图.png modicon 128   # → modicon.tex / modicon.xml（mod 用）
& $py tools\make_ico.py 新图.png player.ico      # → player.ico（播放器用）
```

再重新打包播放器：

```powershell
& $py -m PyInstaller --noconfirm --clean --onedir --windowed --name DSTMusicPlayer ^
    --icon player.ico --collect-all sounddevice --collect-all imageio_ffmpeg player.py
```

最后跑 `tools\sync_mod.ps1` 并重启游戏。

> ⚠️ DST 的本地 mod 放在**游戏安装目录**下的 `mods`，不是 `文档\Klei\...\mods`。
> 这个坑踩过了 —— 放错地方游戏 Mods 界面根本不显示。
>
> 播放器文件夹里的 `_internal` 别删。要搬位置就整个文件夹一起搬。
> **改了源码之后，右键运行 `tools\sync_mod.ps1`**，再重启游戏才生效。

## 用起来

### 1. 开播放器

双击桌面 **饥荒留声机播放器**。

* 点「选择文件夹」挑音乐（mp3 / m4a / flac / wav / ogg 都能放）
* 选过的文件夹会记住
* 游戏没开的时候，它就是个普通播放器

窗口上只有两种状态：

* `游戏没开，正常播放`
* `游戏已开，和留声机同步`

### 2. 游戏里

主菜单 → **Mods** → 勾选「更好的唱片（可连电脑）」→ 应用。

**已经帮你在 `Cluster_3` 里启用了**（`Master` 和 `Caves` 都加了）。
进游戏如果 Mods 里没勾，按 `Esc` → 选项里再勾一次。

mod 设置里有三项：

| 选项 | 说明 | 默认 |
|---|---|---|
| 总音量 | 唱片的最大音量 | 100% |
| 拿起也能放 | 留声机拿在手上/放进背包时音乐继续 | 开 |
| 左右声道 | 听到左右反了就换成「反向」 | 反向 |

> 改完 mod 文件后必须**重启游戏**，游戏只在启动时扫描 mods 目录。

### 3. 摆摊

1. 在「**工具**」页做 **连接电脑** —— **只要 1 根树枝**，不需要科学机器
   - 或控制台 `c_give("pcbridge_record")`
   - 没有留声机：`c_spawn("phonograph")`
2. 把唱片放进留声机 → 电脑出声
3. 走远变小，走回来变大
4. 拿走唱片 → 立刻静音（歌继续走）

## 防崩设计（重要）

用户反馈命门是「不能闪退」。所以：

* **mod 侧**：所有回调都包了 `pcall`，出错只打印一行日志，游戏照常跑。
  和「把留声机拿起来照样播放」那类 mod 不抢东西 —— 只有放的是我们自己唱片时才接管，
  其它情况原样交回给游戏。
* **播放器侧**：音频引擎在独立子进程里，崩了自动重启，界面不受影响。
* **电脑端没开**：完全没影响，mod 只往存档写一个文本文件，没人读就没声音，留声机照常摇。

## 工作原理

```
留声机放上唱片（服务端 Lua）
      |  每 0.5 秒写一次存档里的 dst_music_bridge
      v
action=play  volume=0.732  pan=-0.21  time=1761324589
      |
      v
DSTMusicPlayer.exe（每 0.25 秒读一次）
      |- 留声机没响 -> 输出 0，但解码继续（进度不停）
      |- 留声机响   -> 左右声道按 pan 加权，总音量按距离衰减
      |- 游戏关了   -> 恢复正常播放
```

* **状态文件**：`文档\Klei\DoNotStarveTogether\<玩家id>\Cluster_X\<Master/Caves>\save\dst_music_bridge`
  （饥荒禁止 mod 用 `io.open` 写任意路径，只能写存档目录）
* **心跳**：`dst_music_alive` 每 2 秒更新，停更超过 6 秒就当游戏关了
* **音频**：sounddevice（PortAudio 回调）+ ffmpeg 解码，实测 5 秒 500 个采样块零断点
* **拿在手上**：原版在放进背包时会强制关机，勾了「拿起也能放」后会把那个回调去掉；
  另外拿在手上时 Transform 会被归零，所以这时按「满音量、居中」处理

## 常见问题

**播放器卡、吱哒响**
已经修好了（v0.3 换了低延迟音频引擎）。如果还有，看 `饥荒留声机播放器\player.log`。

**Mods 界面看不到这个 mod**
1. 确认这个文件存在：
   `D:\SteamLibrary\steamapps\common\Don't Starve Together\mods\myfirstmod\modinfo.lua`
2. **完全退出游戏再重开**（游戏只在启动时扫 mods 目录）
3. 还看不到就运行一次 `tools\sync_mod.ps1` 再重启

**游戏里找不到「连接电脑」**
配方在**工具**页，材料只要 1 根树枝，不需要任何科技。控制台 `c_give("pcbridge_record")` 也行。

**拿起留声机就停了**
Mods 菜单里把「拿起也能放」设成「开」。

**播放器显示「游戏已开」，但没声音**
留声机没转或者唱片没放进去。放进唱片后留声机会开始摇，这时才出声。

**双击播放器没反应**
看 `饥荒留声机播放器\player.log` 最后几行。
